
# TravelGo - Agencia de Viajes

## Descripción
TravelGo es un sitio web desarrollado para una agencia de viajes ficticia. Su objetivo es presentar destinos turísticos, paquetes de viaje y ofrecer información de contacto a los visitantes.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Git y GitHub

## Estructura del proyecto
- index.html: página principal.
- destinos.html: catálogo de destinos turísticos.
- paquetes.html: paquetes y preguntas frecuentes.
- contacto.html: información y formulario de contacto.
- css/estilos.css: estilos y diseño responsive.
- js/script.js: funcionalidad del formulario.

## Características
- Diseño tropical y adaptable.
- Navegación entre cuatro páginas.
- Tarjetas de destinos con Flexbox y flex-wrap.
- Acordeón de preguntas frecuentes.
- Formulario de contacto de demostración.
- Diseño responsive para diferentes resoluciones.
